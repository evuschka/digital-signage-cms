# Digital Signage CMS (Прототип)

Система управления медиаконтентом для цифровых экранов. Проект представляет собой прототип трехуровневой архитектуры, включающий объектное хранилище, REST API и пользовательский интерфейс.

## Стек технологий
* **Backend:** Python 3, FastAPI, Uvicorn, Boto3
* **Хранилище:** MinIO (S3-совместимое), Docker Compose
* **Frontend:** Vue.js 3 (через CDN), Tailwind CSS, HTML5

## Функционал
* Загрузка мультимедийных файлов (видео, изображения) через веб-интерфейс.
* Безопасное хранение объектов в изолированном бакете MinIO.
* Автоматическая генерация временных защищенных ссылок (presigned URLs) для трансляции на экраны.
* Удаление неактуального контента из хранилища.
